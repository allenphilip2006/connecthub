# User Manual

## Registration & Login
- Sign up with username, email, and password.
- Login to receive a session token.

## Profile
- View and edit profile details and image.
- Toggle Private Account in Settings.

## Feed
- See posts from followed users mixed with popular posts.
- Like posts and view comments.

## Posts
- Create posts with images/videos and captions.
- Edit, delete, or archive posts.
- Save posts and view them under Saved.
- Repost with attribution to the original author.

## Comments
- Write comments and replies.
- Like and unlike comments.
- Post owners can delete comments.

## Chat
- Select a user to start chatting.
- Typing indicator and real-time messaging.
- Private accounts require accepted follow.

## Search
- Search users by username.
- Use #hashtag to find posts.

## Notifications
- Receive notifications for likes, comments, follows, messages, and mentions.
- View and mark as read.

## Settings
- Privacy, notifications, theme, and language.
- Toggle two-factor placeholder (TOTP integration recommended for production).
